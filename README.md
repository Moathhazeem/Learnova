# 🎓 Learnova

An interactive e-learning platform designed for discovering, managing, and watching educational courses.

---

## 🌟 Key Features
- **Course Catalog:** Browse and search through various categories of courses.
- **Interactive Video Player:** Seamless video playback experience for learners.
- **Responsive Interface:** Tailored for optimal viewing across mobile, tablet, and desktop devices.
- **User Dashboard:** Track learning progress and enrolled courses.

---

## 🛠️ Tech Stack
- **Frontend:** JavaScript, React, HTML5, CSS3
- **Styling:** CSS Modules / Tailwind CSS
